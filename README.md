# 💻 TDU InformatiX Club Website

Welcome to the official repository of the **InformatiX Club** at the Turkish-German University (TDU/TGU). 👋

This project contains the source code for our club's official landing page. 🚀

## 💡 About the Project
This website serves as the digital face of the InformatiX Club. 🌐

It is designed to introduce our core vision, showcase our events (Conferences, Hackathons, Workshops), and provide quick access to our social media channels and WhatsApp community. 📱

## 🛠️ Technical Highlights
The website is built with a minimalist, high-performance approach:
- ⚡ **Vanilla Web Technologies:** Built purely with HTML5, CSS3, and JavaScript. Zero external frameworks or libraries (no Bootstrap, Tailwind, jQuery, etc.) are used.
- 📜 **One-Page Structure:** A seamless, single-page layout with smooth scrolling navigation.
- 🌙 **Material Dark Theme:** A modern, visually appealing dark UI customized for maximum mobile responsiveness.
- ✨ **Custom Canvas Animation:** Features a lightweight, interactive particle network animation in the hero section, rendered entirely with native JavaScript.
